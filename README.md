# Mamoru - Lectura y manejo de datos
## Requisitos

- Node v24.19.0
- npm 11.17.0

## Clonar el repositorio

```bash
git clone https://github.com/Asulx/mamoru-frontend
cd mamoru-frontend
```

## Inicializar el frontend

1. Verifica la versión de Node y npm instalada.

```bash
node --version
npm --version
```

2. Instalar dependencias del proyecto.

```bash
npm install
```

3. Ejecutar el frontend

```bash
npm run dev
```
